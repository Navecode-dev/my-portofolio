---

## 📦 Deployment (Vercel)

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) and log in with GitHub
3. Click **"Add New Project"** → select this repo
4. Click **"Deploy"** — done! ✅

Vercel auto-deploys every time you push a new commit. 🔄
